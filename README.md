## 📖 Sobre el proyecto

Este proyecto funciona como mi portfolio profesional y reúne información sobre mi perfil, tecnologías con las que trabajo, proyectos desarrollados y formas de contacto.

Fue construido como una **Single Page Application con React**, priorizando una interfaz clara, responsive y orientada a facilitar el acceso a la información más relevante de mi perfil profesional.

El portfolio incluye enlaces directos a los repositorios y demos de mis proyectos para poder explorar tanto el resultado final como su implementación.

## ⚛️ Desarrollo

El portfolio está construido mediante componentes de React independientes para cada sección de la interfaz.

```text
src/
│
├── components/
│   ├── Navbar
│   ├── Hero
│   ├── About
│   ├── Skills
│   ├── Projects
│   ├── Career
│   ├── Contact
│   └── Footer
│
├── styles/
│   ├── _variables.scss
│   ├── _reset.scss
│   ├── _typography.scss
│   ├── _navbar.scss
│   ├── _hero.scss
│   ├── _about.scss
│   ├── _skills.scss
│   ├── _projects.scss
│   ├── _career.scss
│   ├── _contact.scss
│   ├── _footer.scss
│   └── main.scss
│
├── App.jsx
└── main.jsx
```

Los estilos están organizados mediante módulos SCSS separados por sección y centralizados desde `main.scss`.

## 📱 Responsive Design

El portfolio fue desarrollado para adaptarse a diferentes tamaños de pantalla, contemplando navegación y distribución de contenido tanto en dispositivos móviles como en escritorio.

Se utilizaron técnicas de diseño responsive mediante **Flexbox, Grid, media queries y SASS**.

## ⚙️ Instalación local

### 1. Clonar el repositorio

```bash
git clone https://github.com/dabouzajm-lang/portfolio-daBouza.git
```

### 2. Ingresar al proyecto

```bash
cd portfolio-daBouza
```

### 3. Instalar las dependencias

```bash
npm install
```

### 4. Ejecutar el entorno de desarrollo

```bash
npm run dev
```

Vite iniciará el servidor de desarrollo y mostrará la URL local correspondiente.

---

## 🏗️ Build de producción

Para generar el build optimizado:

```bash
npm run build
```

Para probarlo localmente:

```bash
npm run preview
```
